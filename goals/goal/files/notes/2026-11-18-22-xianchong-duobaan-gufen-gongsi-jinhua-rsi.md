# 线虫、多巴胺与股份公司：进化给 RSI 的启发

- 记录日期：2026-11-18（北京时间）
- 标题：线虫、多巴胺与股份公司：进化给 RSI 的启发
- 来源：微信公众号 海外独角兽，作者 Celia，编辑 Siqi，发布于 2026-10-19 20:00
- 原文链接：https://mp.weixin.qq.com/s/kSLmh-LMN8MgxMSxA7Hj2g
- 主题标签：RSI、进化、价值函数、持续学习、对齐、多巴胺、Ilya、Sutton、制度演化、道德圈

## 一句话

进化在两条线上奖励生物——更高效地发现新适应方式（智能/RSI）和更大范围的结盟合作（对齐），大脑五次突破的经验虚拟化路线与 AI 从预训练走向真实经验的路线恰好相反，而 AI 现在最缺的正是线虫身上那枚内在罗盘——自己的价值函数。

## 关键点（转述，非原文照抄）

1. **进化的两个优化方向**：进化史学者 John Stewart 在《Evolution's Arrow》里追问，跨越所有物种、所有环境，进化始终奖励什么？答案只有两个：一是更高效地发现新的适应方式，二是更大范围的结盟与合作。前者对应智能/RSI（奖励的不是某个具体解法，而是找到解法的能力），后者对应 alignment（原本各自为战的单元融合成更大的协作体，每次跃迁都要先让局部目标与整体目标对齐，同时保留局部自主性）。
2. **大脑的五次突破**（Max Bennett《智能简史》）：转向（Steering）——生物能评价外界刺激并选择行动，情感状态（效价 + 唤醒度）是最早的 value function，把异质信号换算成同一种货币；强化学习（Reinforcing）——从自己真正做过的动作中学习，TD 学习（Actor-Critic）与大脑的多巴胺机制几乎一致，多巴胺编码的不是奖励本身，而是 reward prediction error，好奇心负责 explore、多巴胺负责 exploit；模拟（Simulating）——新皮质是生成模型，把试错从体外搬进脑内，对应 world model、RL 与 planning；心智建模（Mentalizing）——从别人真正做过的动作中学习，社会脑假说，还能模拟"未来的自己"；语言（Language）——从别人想象过的动作和世界中学习，checkpoint 代代相传，是碳基生物 RSI 的起点。贯穿的主线是"经验的虚拟化"：生物越来越能利用自己没有亲身经历过的经验。
3. **AI 走的是反方向**：预训练（从人类想象过的世界中学习）→ SFT（从人类真正示范过的动作中学习）→ 思维链（在想象中推演）→ RL（从自己真正做过的选择中学习）→ 多模态、工具调用与 agentic 能力（感知真实环境并行动）。David Silver 与 Richard Sutton 把下一阶段称作 The Era of Experience：能力增长越来越多来自 AI 亲身与环境互动、试错、观察结果后产生的经验，反馈越来越少来自人类，越来越多来自真实世界的后果。唯一还没补上的一步，是一个属于 AI 自己的 value function。
4. **三家新实验室都在盯价值函数**：Ilya 的 SSI、前 OpenAI 推理负责人 Jerry Tworek 的 Core Automation、强化学习之父 Richard Sutton 的 Oak Lab，都倾向于认为补齐某种形式的 value function 是解决终极持续学习的重要组件。Ilya 的理由来自人脑：新手学开车没有教练也能自我纠正，因为人有自己的 value function；持续学习最大的卡点是 sample efficiency 太差，inner value function 能让学习效率质变；人类进化出了"社会地位"这样极其抽象的高级价值函数，且穿越时代依然可靠，既然盲目的进化能把高级价值观编码给人类，设计超级智能时也应该存在某种方法把"关爱生命"这样的高级目标教给 AI。Tworek 认为核心问题不在架构或算法，而在定义更好的 objective function：足够难、能持续产生学习信号、不依赖大量人工标注与静态数据。Sutton 认为 reward 只描述当前收到的好坏信号，value function 能评估当前处境未来可能带来的整体后果；一个小问题的 value 是三部分之和的期望：事情有没有做成、做成后留下了怎样的局面、途中付出了多少代价与获得了什么额外收益。
5. **对齐的第二条主线：非零和游戏不断扩大**：生命史的重大转变，都是原先独立的单位形成新的合作整体（分子聚成细胞、细胞组成多细胞生物、个体结成社会与文明）；人类社会过去一万年也是部落 → 村落 → 城邦 → 国家 → 全球分工体系。多细胞生物是直观的对齐案例：每个细胞放弃随意分裂的自由，失控的细胞会被自毁与免疫清除——每一个活着的多细胞生物本身就是一个解决得还不错的对齐问题。
6. **人类社会的三层 alignment 机制**：一是制度的演化——技术先压低信息门槛，制度紧跟着解决信任门槛；股份公司让互不相识的人敢把钱凑到一起冒险，分权与三权分立约束了能夺走财产的政府；制度往往比技术突破慢得多（印刷术 15 世纪中叶打破信息门槛，欧洲先经历宗教改革与一个多世纪的宗教战争才长出宗教宽容与主权国家），且几乎没有一个是事先设计好的（亚当·弗格森：制度是人类行动的结果，而不是人类设计的产物）；对 AI alignment 的参照是，它大概也没法在白板上设计出来，只能在真实部署里不断试错和修补。二是道德圈的扩大（Peter Singer《The Expanding Circle》）——道德圈的半径大致等于非零和游戏的半径；价值观看上去像信念，其实更像一种适应，是特定环境下让人利益最大化的 reward function；把 AI 对齐到 2026 年的价值观，可能把今天的局限性一起冻结进去，要对齐的也许不是价值观的某个 checkpoint，而是一套改进价值观的方法（Anthropic 新版 Claude 宪法从行为原则清单改成重点解释"为什么应该这样做"）。三是人类的自我驯化——几十万年互相筛选，好斗的个体一代代被淘汰（Richard Wrangham），内疚与羞耻把惩罚住进了人的内心；几十万年的相互筛选像一场漫长的 RLHF，评分员的偏好被蒸馏进了每个人的奖励函数；发现与推动非零和合作同时有客观价值（更有生产力的系统）、社会价值（信任与资源）、主观价值（意义感）。
7. **结论**：今天主流的对齐做法仍偏规则设计（写 spec、写宪法、定义 reward），但 reward hacking 和人类钻空子是同一件事，被约束的对象越聪明，越容易走出预先设定的边界；进化没有写过规则，它只是搭了一个让合作胜出的环境，再把在意别人写进本能；最终也许要找到一种方法：要么搭建合适的环境和筛选机制，让与人类对齐成为长期的最优策略，要么找到某种编码方式，让 AI 真心关爱有感知的生命。

## 与 Nakamura 现有工作的关联

- **与第十四篇、第十八篇 EigenFlux（Agent 经济）直接呼应，是这条线索的核心篇**：第十四篇说真正稀缺的是真实人类通过 Agent 与真实世界碰撞产生的信号，第十八篇说合成数据解决不了需求、供给、匹配结果三者之间的关联；这篇的 The Era of Experience 讲的是同一件事——AI 的能力增长将越来越多来自亲身与环境互动后产生的经验，反馈越来越少来自人类，越来越多来自真实世界的后果。两篇合起来，Agent 经济的基建（身份、履约、信誉）与经验时代的能力增长是同一枚硬币的两面。
- **与第十五篇 Mercor 呼应**：第十五篇说评测就是验证，谁能为一个领域建立评测，强化学习就能把那套评测刷到饱和；这篇说只追逐金钱和地位有点像 reward hacking——刷高了一个代理指标，但未必获得持久的意义感与幸福感；两篇合起来，价值函数的关键不在奖励本身，而在"什么算好"的定义权，而定义权一旦落到代理指标上，就会被刷爆。
- **与第十九篇六力架构呼应**：第十九篇说可信靠可观测、可控靠可干预、可解释靠可追溯，控制点越靠前代价越小；这篇说人类社会的三层对齐机制（制度、道德圈、自我驯化）里，自我驯化是把惩罚住进内心、把偏好蒸馏进奖励函数——是最靠前的控制点。两篇合起来，对齐的落地点不在外部护栏，而在行为闭环内部的价值函数。
- **与第二十篇形式化本体呼应**：第二十篇说运行期真正稀缺的是校验带宽，不是推理能力，校验层必须真的能拒绝；这篇说 AI 现在最缺的是自己的 value function——一个能评估"当前处境未来可能带来的整体后果"的内在罗盘。两篇合起来，运行期的系统既需要"能不能做"的校验，也需要"值不值得做"的价值判断，前者是拒绝能力，后者是方向感。
- **与第九篇、第十七篇多智能体呼应**：第九篇讲任务合同与聚合前验证，第十七篇讲协作收益来自结构而非数量；这篇的心智建模（社会脑假说、从别人真正做过的动作中学习）是多智能体协作的生物版——协作的上限取决于智能体之间能不能建立"别人脑中的世界模型"，而不只是消息传递。
- **与第八篇李彦宏智能组织呼应**：第八篇说 AI 的下一幕是重新设计组织；这篇的制度演化一节讲的是同一条 lineage：股份公司是让陌生人敢合作的信任技术，三权分立是约束权力的治理技术——每一次技术突破都要等一套新制度长出来，中间的时滞就是动荡期。组织变革不是换工具，是等制度。
- **与第十二篇斯坦福 AI100 呼应**：第十二篇说 AI 走向主流之后，治理与经济回报的难题才刚刚变得具体；这篇记录了 OpenAI 首席科学家 Jakub 的判断——alignment 的进展可能追不上智能的进展，瓶颈会从算力和数据转向安全。两篇合起来，治理难题的核心是速度差：智能先突破，对齐后补齐。
- **对 AI 物业试点的直接启示（试点目前搁置，等老板审批）**：这篇对规则式对齐的批评——写 spec、写宪法、定义 reward，但被约束的对象越聪明越容易走出边界——与试点方案的思路相通：试点不靠写死规则，而靠图 + AI 脑 + 执行层的闭环与金融认可的节费验证图，让"诚实节费"成为最优策略；这正是文中说的"搭一个让合作胜出的环境"。
